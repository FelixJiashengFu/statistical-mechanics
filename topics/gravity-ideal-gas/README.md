# 重力场中的理想气体

水墨风格的单文件讲解页，对应习题 Question 6 (Ideal Gas, Part 2)：从巨正则配分函数推出等温气压公式。

[打开交互页](index.html)

## 内容

- **模型**：均匀重力场中的理想气体，温度处处相同，体系无限大，局域平衡。高度 `z` 处 `N` 个分子的势能为 `Mgz`，`M = mN`。
- **第一问**：局域体积内 `H = H₀ + Nmgz`，代入巨正则配分函数的定义得式 (2.3.6)。
- **第二问**：`Nmgz` 与相空间坐标无关，提出积分后并入 `e^{βμN}`，得 `Q(μ, V, T, z) = Q(μ − mgz, V, T, 0)`。再用理想气体的 `p = kT·e^{βμ}/Λ³`，得 `p(z) = p(0)·e^{−βmgz}`，即式 (2.3.7)。
- **检查**：流体静力学 `dp/dz = −ρmg`，以及单分子玻尔兹曼因子。

## 交互图

- 左栏墨点表示分子，地面数密度固定，按 `e^{−z/H}` 取舍；右栏是同一高度轴上的 `p/p₀` 曲线。
- 可调参数：气体（H₂、He、N₂、O₂、CO₂、Xe）和温度（100–600 K）。
- 读数：标高 `H = kT/mg`、珠峰顶（8.85 km）的 `p/p₀`、气压减半高度 `H ln 2`。
- 常数：`k = 1.380649×10⁻²³ J/K`，`g = 9.81 m/s²`，原子质量单位 `1.66054×10⁻²⁷ kg`。

## 适用范围

推导是精确的解析结果。交互图是教学示意：墨点是随机抽样，山形只有最高峰按 8.85 km 定标；真实大气并不等温，也不是单一组分。
