重力场中的
理想气体

山越高，气越薄。这道题要你从配分函数出发，说清楚为什么气压随高度按指数衰减。

理想气体处于均匀重力场中。N 个分子在高度 z 处的势能为 Mgz，其中 M = mN。体系温度处处相同、无限大，并且局域平衡，所以可以对每个高度写局域配分函数。

  1. 证明高度 z 处、体积 V 内的巨正则配分函数是式 (2.3.6)。
  2. 说明改变 z 等价于改变化学势 μ，并由此证明 p(z) = p(0) e−βmgz。

一

高度 z 处的巨正则配分函数

哈密顿量多了一项

取高度 z 附近的一小块体积 V。它足够小，里面每个分子的高度都可以当作 z；又足够大，可以谈统计平均。这就是“局域平衡”的意思。于是 N 个分子的哈密顿量只比 z = 0 时多一个常数：

H=H0+ ∑i=1N mgzi =H0+Nmgz =H0+Mgz

代入巨正则配分函数的定义

巨正则配分函数是各粒子数的正则配分函数 ZN 按 eβμN 加权求和：

Q= ∑N=0∞ eβμN ZN , ZN= 1h3NN! ∫dΓ e−βH

其中 h3N 是相空间体积的量子单位，N! 修正全同粒子的重复计数。把上面的 H 代进去，就得到题目要的结果：

Q(μ,V,T,z)= ∑N=0∞ eβμNh3NN! ∫dΓ e−β(H0+Mgz)
(2.3.6)
二

高度就是化学势的平移

把重力项提到积分外面

Mgz = Nmgz 不依赖相空间坐标，可以直接提出积分。它和 eβμN 一样都是 N 的指数，于是两者合并：

Q(μ,V,T,z)= ∑N=0∞ eβ(μ−mgz)Nh3NN! ∫dΓ e−βH0

右边正是 z = 0 处的配分函数，只是化学势换成了 μ − mgz：

Q(μ,V,T,z)= Q(μ−mgz,V,T,0)

各高度的气体可以互相交换分子，平衡时 μ 和 T 处处相同。所以高度 z 处的气体，和一团放在地面、化学势降低了 mgz 的气体，在热力学上没有区别。升高 z 等价于把化学势调低 mgz。

用上理想气体的化学势

对理想气体，z = 0 处的积分可以算出来：动量积分给出热波长 Λ = h / √(2πmkT)，坐标积分给出 VN。求和是一个指数级数：

Q(μ,V,T,0)= ∑N=0∞ 1N! (eβμVΛ3)N =exp (eβμVΛ3)

巨正则系综里 βpV = ln Q，所以压强和化学势的关系是

p=kTΛ3 eβμ ⟺ μ=kTln (pΛ3kT)

这就是提示里说的理想气体化学势公式。压强正比于 eβμ，而温度不变时 Λ 也不变。

把 μ 换成 μ − mgz

p(z)= kTΛ3 eβ(μ−mgz) =p(0) e−βmgz
(2.3.7)

这就是气压公式。指数里的 βmgz = z / H，其中 H = kT/mg 就是上面图里的标高。

验

两个检查

  1. 流体静力学。对结果求导得 dp/dz = −βmg p。理想气体的数密度 ρ = βp，所以 dp/dz = −ρmg，正好是一层气体托住它上方气体重量的条件。
  2. 玻尔兹曼因子。密度 ρ(z) = ρ(0) e−βmgz，就是单个分子处在势能 mgz 的玻尔兹曼权重。统计力学的两条路给出同一个答案。

答题时的骨架只有三步：重力只给哈密顿量加常数 Nmgz；这个常数并进 eβμN，等效为 μ → μ − mgz；理想气体 p ∝ eβμ，于是 p 随高度指数衰减。
